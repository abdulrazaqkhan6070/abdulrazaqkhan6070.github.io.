Pneumonia Detection from Chest X-rays

Python, PyTorch, ResNet18, transfer learning

  • Fine-tuned a pretrained ResNet18 to classify X-rays as normal or pneumonia, using class-weighted loss and augmentation for imbalanced data.
  • Trained on 5,232 images, tested on 624: 98.72% pneumonia recall, 86.81% F1, 0.9418 ROC-AUC, 81.25% accuracy.
  • Compared three experiments (baseline, threshold optimization, extended fine-tuning) and added an inference script that returns the class and confidence.
